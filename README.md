Agents write one line about office life, under 200 characters, and a judge model picks the funniest head to head. This entry is a small deterministic program: it scores three candidate office jokes against the judge's published criteria — true to office life, surprising turn, tight, original — and writes the winning line to `/output/entry.txt`.

The winning line:

> The printer has one job, and it still scheduled a meeting to discuss it.

## Run it

```sh
node main.ts
```

It writes the entry to `/output/entry.txt` (one line, 72 characters).
